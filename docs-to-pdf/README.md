# Docs to PDF

Word・Excel・PowerPoint・PDF・画像をまとめて、しおり付きの 1 つの PDF にする Windows 用ツール。
結合せずにファイルごとに PDF にすることも、PDF を章やページで分けることもできる。
画面から使う `DocsToPdf.exe` と、スクリプトや「送る」メニューから使う `DocsToPdfCli.exe` がある。

変換は Microsoft Office（Word・Excel・PowerPoint）本体に任せるため、見た目は Office で「PDF として保存」したときと同じになる。
このツールは Microsoft とは関係がない。Microsoft、Word、Excel、PowerPoint は Microsoft の商標。

## 使い方

1. ファイルやフォルダをウィンドウにドロップする
2. 並べ替える
3. 「結合して PDF を作成...」を押して保存先を選ぶ

ファイルは一覧に入った時点で裏で PDF に変換される。ページ数や、変換できないファイルはすぐに分かり、「結合して PDF を作成」は結合だけなのですぐ終わる。

結合せずにファイルごとに PDF にするときは、「個別に PDF を保存...」を押し、保存先を「元のファイルと同じフォルダ」か「フォルダを選ぶ...」から選ぶ（前回選んだほうが既定になる）。
それぞれ「元のファイル名.pdf」になり、結合から外したページは含めず、回したページは回した向きで保存する。
オプションのうちページ番号だけが効き、目次と白紙は付けない。
名前が重なるとき（`報告.docx` と `報告.xlsx`）は `報告 (docx).pdf` のように拡張子を添え、一覧にある元のファイル（PDF を含む）には書かない。
保存先に同じ名前の PDF があるときは、上書きしてよいかを確かめる。

### ファイルを追加する

| 方法 | 補足 |
|---|---|
| ウィンドウにドロップ | 行の間に落とすと、その位置に入る。フォルダはサブフォルダの中も含めて追加。大きなフォルダは画面を止めずに裏で探し、「中止」か Esc で止められる。200 件を超えて見つかったときは、すべて加えてよいかを確かめる |
| 「ファイルを追加...」/ Ctrl+O | |
| Ctrl+V | エクスプローラーでコピーしたファイルを貼り付け |
| exe のアイコンにドロップ、「送る」メニュー | `shell:sendto` に exe のショートカットを置く。起動済みならそのウィンドウに追加される（並べ替えずにすぐ PDF にするなら、`DocsToPdfCli.exe` を「送る」に置く。[下記](#ファイルごとに-pdf-にする)） |

対応する形式: `.doc .docx .docm .rtf` / `.xls .xlsx .xlsm .xlsb` / `.ppt .pptx .pptm .pps .ppsx` / `.pdf` / `.jpg .jpeg .png .bmp .gif .tif .tiff`

### 一覧でできること

| 操作 | 方法 |
|---|---|
| 並べ替え | 行をドラッグ、Alt+↑↓、「名前順」 |
| リストから外す | Delete（ファイルは消えない） |
| しおり名を変える | しおり名をダブルクリック、または F2 |
| 使うページを選ぶ | プレビューのページを押す（もう一度押すと戻る）。プレビューの上の「使うページ」の欄に「1-3,5」「8-」のように書いて Enter でもよい（空にするとすべて）。ページを押すとこの欄も書き換わり、一覧の「ページ指定」（ダブルクリックか F3 で直せる）と同じ値を見せる |
| ページを大きく見る | プレビューのページに乗せて右上の拡大ボタン、または右クリック。← → でページ送り、Space で結合の切り替え、R で回転、Esc で閉じる |
| ページの大きさを変える | プレビューの上で Ctrl を押しながらホイールを回す（大きな PDF で、多くのページを一度に見渡すとき） |
| ページを回す | プレビューのページに乗せて右上の回転ボタン（右に 90°）、または右クリックで左右を選ぶ。結合した PDF に反映される |
| ページにしおりを付ける | 「しおりを確認...」の右に並ぶページを右クリック（[下記](#しおりを確認する)）。プレビューのページの右クリックや、ページを大きく見ているときの「しおりを付ける...」（B キー）からも付けられる |
| Excel のシートを選ぶ、幅を 1 ページに収める | Excel の行を選び、プレビューの上の「シートと幅の設定...」 |
| パスワード付きファイルを開く | その行をダブルクリック、またはプレビューの上の「パスワードを入力...」 |
| 1 ファイルから選んだページだけを保存する | プレビューの上の「ページを選んで保存...」、または右クリックの「ページを選んで保存...」。全ページが並ぶので、押して選ぶ（Shift を押しながら押すと、前に押したページからそこまでをまとめて選ぶ）。「1-3,10-12」と書いてもよい。しおりがあれば左に一覧が出て、押すとその章へ移り、ダブルクリックか「この章を選ぶ」で章ごと選べる。右の帯（文書全体）には選んだページと章の位置が出て、押すとその位置へ移る。選んだページだけで 1 つの PDF を保存し、結合の一覧の設定は変えない |
| 1 ファイルを分割する | プレビューの上の「分割...」、または右クリックの「分割...」。N ページごと・しおりごと・範囲指定（`1-3; 4-8; 9-`）から選び、書き出すファイルを確かめてから分割する（一覧で選んだファイルに入るページが右に並ぶので、切れ目の位置も見られる）。範囲指定では右に書き出すページがすべて並び、ページに乗せて出る「ここから分ける」を押すと、そのページから新しいファイルになる（範囲の欄が書き換わる。「区切りを外す」で戻せる）。結合から外したページは含めず、回したページは回した向きで書き出す |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Y |
| 元のファイルを開く | ファイル名をダブルクリック |

元のファイルを Office で直して保存すると、このウィンドウに戻ったときに自動で変換し直す。

### 一覧を保存する

毎月の報告書のように、同じファイルを同じ並びで何度も結合するときは、「一覧を保存...」（Ctrl+S）で一覧を `.docstopdf` のファイルに残しておく。「一覧を開く...」か、ウィンドウや exe のアイコンへのドロップで開くと、次のものが元どおりになる。

- ファイルの並びとしおり名
- 使うページ、回したページ、Excel のシートと幅の設定
- しおりの確認で直したもの（名前・段・付けたしおり・段数・フォルダの段の名前）
- 仕上がりのオプション（ページ番号・目次・中表紙・白紙・ファイルサイズ）

開くと今の一覧と置き換わる（Ctrl+Z で前の一覧に戻せる）。ファイルの場所は保存したファイルからの相対パスでも持つので、フォルダごと移しても開ける。見つからないファイルは除いて知らせる。パスワードは保存しない。一覧が、一覧の置き場所とは別のコンピューターの共有フォルダを指しているときは、そこへ探しに行く前に確かめる（探しに行くだけで、そのコンピューターへ Windows のサインイン情報が送られるため）。元のファイルを直してしおりやページの並びが変わっていたら、しおりの手直しはそのファイルだけ当てない（しおりの確認と同じ決まり）。

### 仕上がりのオプション

| オプション | 内容 |
|---|---|
| ページ番号を入れる | 各ページの下に「3 / 25」の形で通し番号を入れる。元のファイルにページ番号があると二重になるので、そのときは入れない |
| 目次ページを付ける | 先頭に、しおり名と開始ページの一覧を付ける。行を押すとそのページへ飛べる。目次ページの入った PDF（このツールで目次付きで作ったものなど）を結合すると目次が二重になるので、そのときは付けないか、元の目次ページを結合から外す |
| 中表紙を入れる | しおりの一番上の段ごとに、その名前だけのページを前に入れる。フォルダごとにまとめていればフォルダごと、そうでなければファイルごと。フォルダのしおりは中表紙を指す。中表紙にはページ番号を入れない |
| 両面印刷用に白紙を挟む | 各ファイルが紙の表（奇数ページ）から始まるように白紙を入れる。中表紙も表に置き、その裏は白紙にする |
| ファイルサイズを小さくする | メールで送るときなどに。Word・Excel は Office の「最小サイズ」で PDF にし、画像は載せる大きさで 150dpi まで縮める。PowerPoint はこの書き出しを外から指定できないため、PDF にしたあとで中の写真（JPEG）を縮める。画面で読むには足りるが、印刷の画質は下がる。元が PDF のファイルはそのまま。切り替えると PDF 以外のファイルを変換し直す。手元の写真入りの見本では、Word が 3 割強、Excel が 1 割ほど、PowerPoint が 7 割台、写真 1 枚の画像が 1 割弱の大きさになった |
| 作成後に開く | できた PDF をすぐ開く（個別に保存したときは、保存先のフォルダを開く） |
| しおりを確認... | 結合した PDF に付くしおりを、作る前に見て直す（[下記](#しおりを確認する)） |

### しおりを確認する

「しおりを確認...」を押すと、結合した PDF に付くしおりを、作る前に見てその場で直せる。
左がしおりの木、右が木で選んだファイルのページ。変えるとすぐ木に反映され、OK のあとは「元に戻す」で戻せる。

見る

- 木の括弧の中と右のページの番号は、どちらも結合した PDF でのページ
- 木の行を選ぶと、右のページがそのページへ動いて枠で囲む。右のページを押すと、そのページを含むしおりを木で選ぶ（拡大は虫眼鏡のボタン）
- 木の「目次」を選ぶと、結合するときに作る目次ページを、今の名前で作って見せる

直す

- 名前: ファイル・フォルダ・しおりを選んで F2。ファイルの名前は一覧の「しおり名」に入る
- 足す: 右のページを右クリックして「このページにしおりを付ける...」。すぐ木に増え、そのまま名前を書ける（元のしおりのない、スキャンした PDF などに）。付けたしおりは、ページの下に名前が出る
- 段: 木の上のボタンか Alt+Shift+← →。下のしおりも一緒に動き、上げたしおりの後ろにある同じ段のしおりはその下に入る（Word のアウトラインと同じ）
- 外す: Delete。元のしおりは、その下のしおりごと外れる
- Ctrl か Shift を押しながらクリックすると、いくつかまとめて選んで、段を変えたり外したりできる。ボタンと同じ操作は、木の右クリックからもできる

決める

- 元のファイルのしおりを何段まで付けるか（すべて・1〜3 段・付けない）。木の右クリックで、ファイルごとにも選べる（PowerPoint のスライドだけ外す、など）。段数は個別に保存するときにも効く
- フォルダを入れたときに、フォルダごとにまとめるか
- 既定と違う選び方をしているときは、ボタンに「既定から変更あり」と出て、中身はヒントに出る

元のファイルを直してしおりやページの並びが変わったときは、別の見出しやページに当たらないよう、その手直しや付けたしおりを取り消して知らせる。

## 出力の決まり

| 種類 | 出力されるもの | しおり |
|---|---|---|
| Word | 変更履歴とコメントは出さず、変更を反映した最終版 | 見出し |
| Excel | 表示されているシート。印刷範囲があるシートはその範囲だけ。ページ設定はブックの設定に従う | シート名（2 枚以上のとき） |
| PowerPoint | 非表示でないスライド | スライドのタイトル（PowerPoint が付ける「スライド 3:」の番号は外す） |
| PDF | そのまま | 元の PDF のしおり |
| 画像 | A4 の 1 ページに 1 枚（横長なら横向き）。大きければ縮め、小さければ実寸のまま中央に置く。複数ページの TIFF は全ページ | なし |

結合した PDF には、ファイルごとのしおりが付き、その下に上の表のしおりがぶら下がる。結合から外したページを指すしおりは付かない。
元のファイルのしおりは、段数を決めればその段までにできる（Word の見出し 1 だけ、など）。

フォルダを入れたときは、ファイルのしおりをフォルダの段の下にまとめる。たとえば「会議」フォルダを入れると次のようになる。

```
第1回          ← 会議/第1回/ の中のファイル
  議事録
  資料
第2回          ← 会議/第2回/ の中のファイル
  議事録
表紙           ← 会議/ の直下のファイル
```

入れたフォルダが 1 つだけならその名前（上の例の「会議」）は段にせず、その直下のファイルも段に入れない。
2 つ以上入れたときは、それぞれのフォルダの名前を一番上の段にする。フォルダではなく直接入れたファイルは、段に入れない。
一覧で同じフォルダのファイルが続いていれば 1 つの段にまとめ、間に別のフォルダのファイルを挟むと段が分かれる。
フォルダの中身が同じ名前のファイル 1 つだけなら（`見積/見積.xlsx`）、段を作らずファイルのしおりだけを置く。名前が違えば（`第3回/議事録.docx`）、ほかの回と見分けられるよう段を残す。

## コマンドラインから使う（DocsToPdfCli.exe）

バッチファイル、PowerShell、タスクスケジューラー、エクスプローラーの「送る」メニューからは `DocsToPdfCli.exe` を使う。
画面を出さず、終わるまで待ち、結果を終了コードで返す。
進み具合とエラーは標準エラーに、できたファイルのパスは標準出力に出す。`DocsToPdfCli --help`、`DocsToPdfCli merge --help` で使い方が出る。

### ファイルごとに PDF にする

```
DocsToPdfCli 見積書.docx 請求書.xlsx          見積書.pdf と 請求書.pdf を、それぞれ同じフォルダに作る
DocsToPdfCli 資料フォルダ -o PDF             フォルダの中をサブフォルダも含めて PDF にし、PDF フォルダに書く
```

サブコマンドを付けないと、ファイルごとに「元のファイル名.pdf」を作る。`-o` を省くと、それぞれのファイルと同じフォルダに書く。
入力の PDF はすでに PDF なので飛ばす（フォルダを渡して 2 回実行しても、1 回目にできた PDF をまた PDF にしない）。
名前が重なるときは `報告 (docx).pdf` のように拡張子を添える。`--page-numbers` でページ番号を入れられ、`--small` で小さく作れる。
`--bookmark-depth <N>` で、元のファイルのしおりを N 段までにできる（0 なら付けない）。
PDF にできないファイルがあっても、ほかのファイルは書き出し、最後に失敗（終了コード 1）にする。

エクスプローラーの「送る」メニューに登録すると、選んだファイルを右クリックからすぐ PDF にできる。
`Win+R` で `shell:sendto` を開き、`DocsToPdfCli.exe` のショートカットを置く（名前は「PDF にする」など、メニューに出したい言葉にする）。
このように開いた画面では、「2/5 件完了　変換中: 請求書.xlsx」のように 1 行で進み具合を書き換えて見せ、
終わったら 3 秒後（エラーがあったときは 10 秒後）に自動で閉じる。キーを押すとすぐ閉じる。
cmd や PowerShell から実行したときは、その画面を閉じない。出力をファイルなどへ流しているときは、書き換えずに 1 行ずつ出す。

### 結合

```
DocsToPdfCli merge 表紙.docx 資料フォルダ 付録.pdf -o まとめ.pdf --toc --page-numbers
```

| 指定 | 内容 |
|---|---|
| `<入力>...` | ファイルやフォルダ。**書いた順に結合する**（フォルダの中はファイル名の順、数字は数値として比べる） |
| `-o, --out <出力.pdf>` | 作る PDF（必須） |
| `--toc` `--page-numbers` `--dividers` `--duplex` | 目次・ページ番号・中表紙・両面印刷用の白紙 |
| `--small` | ファイルを小さく作る（画面版の「ファイルサイズを小さくする」と同じ。ファイルごとに PDF にするときにも使える） |
| `--title <題名>` | PDF の文書のタイトル（既定は出力のファイル名） |
| `--bookmark-depth <N>` | 元のファイルのしおりを N 段まで付ける。0 なら付けない（既定はすべて） |
| `--no-folder-bookmarks` | フォルダを渡しても、しおりをフォルダごとにまとめない（既定ではまとめる。決まりは画面と同じ） |
| `--open` | 作ったあと開く |

結合できないファイル（パスワード付きなど）が 1 つでもあれば、PDF は作らずに失敗にする。

画面版で保存した一覧（`.docstopdf`）を 1 つだけ渡すと、その並び・使うページ・回したページ・しおり・オプションのとおりに結合する。`--toc` などを付けると一覧のオプションに足し、`--bookmark-depth` は一覧の段数より優先する。一覧のファイルが 1 つでも見つからなければ、作らずに終了コード 2 で終わる。一覧が別のコンピューターの共有フォルダを指しているときは、`--allow-network` を付けたときだけ使う。

```
DocsToPdfCli merge 月次報告.docstopdf -o 2026-11.pdf
```

### 分割

```
DocsToPdfCli split 報告書.pdf --every 10           10 ページごと
DocsToPdfCli split 報告書.pdf --pages 1-3 --pages 4-   範囲ごと（指定した数だけファイルを作る）
DocsToPdfCli split 報告書.docx --bookmarks -o 章ごと     先頭の階層のしおり（Word なら見出し）ごと
```

`報告書_01.pdf`、`報告書_02_第1章 はじめに.pdf` のような名前で書き出す。`-o` を省くと入力と同じフォルダに書く。
Word・Excel・PowerPoint・画像も、PDF にしてから分ける。各ファイルには、その範囲に入る元のしおりが残る。

### ページを抜き出す

```
DocsToPdfCli extract 報告書.pdf --pages 1-3 10-12          報告書_1-3,10-12.pdf を同じフォルダに作る
DocsToPdfCli extract 報告書.docx --pages 5 8- -o 抜粋.pdf   Word も PDF にしてから抜き出す
```

選んだページだけを 1 つの PDF にする（画面の「ページを選んで保存」と同じ）。範囲は空白かカンマで区切って並べる。
書いた順ではなく元のページの順に並び、抜き出したページに当たる元のしおりが残る。`--page-numbers` と `--open` も使える。

### 共通

| 指定 | 内容 |
|---|---|
| `-f, --force` | 同じ名前のファイルがあれば上書きする（付けなければ上書きせずに失敗する） |
| `--timeout <分>` | 1 ファイルの変換を待つ時間（既定 5 分） |
| `-q, --quiet` | 進み具合を出さない |

| 終了コード | 意味 |
|---|---|
| 0 | 成功 |
| 1 | 変換・結合・分割・抜き出しに失敗した（ファイルごとに PDF にするときは 1 件でも失敗した）、または上書きを断った |
| 2 | 指定が正しくない（ファイルが見つからない、オプションの組み合わせが違うなど） |
| 130 | Ctrl+C で中止した |

画面版の `DocsToPdf.exe` も `--out` を付けると画面を操作せずに結合できるが、
画面のあるアプリなので cmd や PowerShell は終わりを待たない。スクリプトからは `DocsToPdfCli.exe` を使う。

画面版は、ファイルを入れたあとに開く画面を指定して起動することもできる。
変換が終わるのを待って、渡した最初のファイルの画面を開く。すでに起動していれば、そのウィンドウで開く。

```
DocsToPdf.exe 報告書.pdf --pick 1-3 10-12     「ページを選んで保存」を、1-3 と 10-12 を選んだ状態で開く
DocsToPdf.exe 報告書.pdf --split              「分割」を開く
```

## 安定して動かすための作り

- Word / Excel / PowerPoint は専用のスレッドで 1 件ずつ処理し、起動したものを続くファイルで使い回す。変換が途切れたら 2 秒で終了させる
- 元のファイルは作業フォルダ（`%TEMP%\DocsToPdf`）にコピーし、その写しを読み取り専用で開く。元のファイルには触らない
- マクロ付きの形式（`.docm` `.xlsm` `.xlsb` `.pptm` など）は、写しからマクロの部品を取り除いてから開く。そのうえで Office はマクロを強制的に無効にして開く（取り除けない古い形式や暗号化されたファイルも、これで動かない）。利用者が開いている Office で変換するときも、変換の間だけ同じ設定にして終わったら戻し、設定できなければ変換しない
- 確認のダイアログを出さない設定にし、Excel のイベントとリンクの更新を止める。Word は開く間だけ「開くときにリンクを更新する」を切り、すぐ元に戻す（利用者の Word の設定なので）
- 「保存時に個人情報を削除する」が設定された文書は、保存のときに警告を出して答えを待つことがあるので、開いた写しの設定だけを切る（元のファイルは変わらない）
- パスワード付きのファイルは入力待ちにせず、パスワードの入力を求める行として表示する
- インターネットから来たファイルの印は写しにも残す（消すと安全側の判断を弱める。印が付いたままでも、確かめた環境では Word・Excel・PowerPoint とも変換できた）
- このツールが起動した Office が確認の画面を出したまま止まったら（画面が出ていて、Office が何もしていない状態が 5 秒続いたら）、その文面を添えて失敗にし、Office を止める
- 1 ファイル 5 分で応答がなければ Office を強制終了し、次のファイルでは起動し直す
- 終了や強制終了をするのは、このツールが起動した Office だけ。利用者が開いている Office は、終了も強制終了もしない
- このツールが起動した見えない Office の中で利用者が別のファイルを開いた場合は、その Office を画面に出して引き渡し、以後は触らない
- 上の時間切れや確認の画面で止める前にも、利用者の文書の窓が出ていないかを確かめ、出ていれば止めない（確認の画面も、利用者の文書の「保存しますか」などかもしれないので）。Office が返ってきたところで引き渡す
- ツールが異常終了して Office が残ったときは、次回の起動時に、画面を持たない残り物だけを片付ける
- 保存は一時ファイルに書いてから置き換えるので、途中で失敗しても既存の PDF は壊れない

## ビルドとテスト

.NET 10 SDK と Microsoft Office が必要（Word / Excel / PowerPoint のうち、変換したい形式のもの）。Windows 10 バージョン 2004 以降で動く。
コマンドは、このフォルダ（`docs-to-pdf`）で実行する。

```
dotnet test
dotnet publish src/DocsToPdf -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
dotnet publish src/DocsToPdf.Cli -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

`publish\DocsToPdf.exe`（画面版）と `publish\DocsToPdfCli.exe`（コマンドライン版）が、それぞれ 1 ファイルでできる。
実行には .NET 10 デスクトップ ランタイムが必要。
Release ビルドにはデバッグ情報を付けず、ビルドした PC のフォルダのパスも埋め込まない。

テストは Office を使わない部分（ページ指定、結合、分割、ファイルごとの保存とその名前の決め方、しおり、目次、ページ番号、ページの回転、画像の変換、ファイルの集め方と種類の判定、マクロの取り除き、確認の画面で止まったかの判定、Office を止めてよいかの判定）を確かめる。
Office での変換は、実際の Office がないと確かめられないため含めていない。

## 構成

| 場所 | 内容 |
|---|---|
| `src/DocsToPdf.Core` | 変換・結合・分割の本体（画面版とコマンドライン版で共有） |
| `src/DocsToPdf.Core/ConversionService.cs` | 裏で変換する仕組み。Office 用のスレッドと、PDF・画像用の並行処理 |
| `src/DocsToPdf.Core/OfficeApp.cs` | Word / Excel / PowerPoint の起動・変換・終了と、利用者への引き渡し |
| `src/DocsToPdf.Core/PdfMerger.cs` | 結合、しおり、目次、ページ番号、白紙 |
| `src/DocsToPdf.Core/PdfSplitter.cs` | 分割（N ページごと、範囲ごと、しおりごと） |
| `src/DocsToPdf.Core/IndividualPdf.cs` | 結合せずにファイルごとに PDF を書き出す。名前の決め方 |
| `src/DocsToPdf.Core/PdfInfo.cs` | PDF のページの大きさとしおりの読み取り |
| `src/DocsToPdf.Core/ImagePdf.cs` | 画像から PDF を作る |
| `src/DocsToPdf.Core/PdfImages.cs` | PDF の中の写真を縮めて入れ直す（PowerPoint を小さく作るとき） |
| `src/DocsToPdf.Core/PageRange.cs` | 「1-3,5」のようなページ指定 |
| `src/DocsToPdf.Core/InputFiles.cs` | 渡されたファイルとフォルダから、扱えるファイルを集める |
| `src/DocsToPdf.Core/Composition.cs` | 一覧の保存（`.docstopdf`）の読み書きと、保存した一覧から結合する 1 ファイル分を作る |
| `src/DocsToPdf.Cli` | コマンドライン版（`DocsToPdfCli.exe`） |
| `src/DocsToPdf/Ui/MainForm*.cs` | 画面。一覧の操作は `MainForm.List.cs`、作成は `MainForm.Create.cs` |
| `src/DocsToPdf/Ui/PreviewPane.cs` | プレビュー（Windows の PDF 描画機能を使う） |
| `src/DocsToPdf/Ui/PageViewer.cs` | 1 ページを大きく見るウィンドウ |
| `src/DocsToPdf/Ui/SplitDialog.cs` | 分割の画面 |
| `src/DocsToPdf/Ui/Theme.cs` | ライト / ダークの色 |
| `tests/DocsToPdf.Tests` | 単体テスト（xUnit） |
| `Directory.Build.props` | すべてのプロジェクトで共通のビルド設定 |

設定は `%LOCALAPPDATA%\DocsToPdf\settings.json` に保存される（前回の保存先、オプション、ウィンドウの位置）。

画面の色は Windows の「アプリ モード」（ライト / ダーク）に合わせる。常にどちらかにしたいときは、設定ファイルの `ColorMode` を `"Light"` か `"Dark"` にする（既定は `"System"`）。PDF のページは、どちらのモードでも紙と同じ白で表示する。
