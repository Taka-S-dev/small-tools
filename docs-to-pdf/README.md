# Docs to PDF

Word・Excel・PowerPoint・PDF・画像をまとめて、しおり付きの 1 つの PDF にする Windows 用ツール。
結合せずにファイルごとに PDF にすることも、PDF を章やページで分けることもできる。
画面から使う `DocsToPdf.exe` と、スクリプトや「送る」メニューから使う `docs2pdf.exe` がある。

変換は Microsoft Office（Word・Excel・PowerPoint）本体に任せるため、見た目は Office で「PDF として保存」したときと同じになる。
このツールは Microsoft とは関係がない。Microsoft、Word、Excel、PowerPoint は Microsoft の商標。

## 使い方

1. ファイルやフォルダをウィンドウにドロップする
2. 並べ替える
3. 「結合して PDF を作成...」を押して保存先を選ぶ

ファイルは一覧に入った時点で裏で PDF に変換される。ページ数や、変換できないファイルはすぐに分かり、「結合して PDF を作成」は結合だけなのですぐ終わる。

結合せずにファイルごとに PDF にするときは、「個別に PDF を保存...」を押し、保存先を「元のファイルと同じフォルダ」か「フォルダを選ぶ...」から選ぶ（前回選んだほうが既定になる）。
それぞれ「元のファイル名.pdf」になり、結合から外したページは含めず、回したページは回した向きで保存する。
オプションのうちページ番号だけが効き、目次と白紙は付けない。
名前が重なるとき（`報告.docx` と `報告.xlsx`）は `報告 (docx).pdf` のように拡張子を添え、一覧にある元のファイル（PDF を含む）には書かない。
保存先に同じ名前の PDF があるときは、上書きしてよいかを確かめる。

### ファイルを追加する

| 方法 | 補足 |
|---|---|
| ウィンドウにドロップ | 行の間に落とすと、その位置に入る。フォルダはサブフォルダの中も含めて追加。大きなフォルダは画面を止めずに裏で探し、「中止」か Esc で止められる。200 件を超えて見つかったときは、すべて加えてよいかを確かめる |
| 「ファイルを追加...」/ Ctrl+O | |
| Ctrl+V | エクスプローラーでコピーしたファイルを貼り付け |
| exe のアイコンにドロップ、「送る」メニュー | `shell:sendto` に exe のショートカットを置く。起動済みならそのウィンドウに追加される（並べ替えずにすぐ PDF にするなら、`docs2pdf.exe` を「送る」に置く。[下記](#ファイルごとに-pdf-にする)） |

対応する形式: `.doc .docx .docm .rtf` / `.xls .xlsx .xlsm .xlsb` / `.ppt .pptx .pptm .pps .ppsx` / `.pdf` / `.jpg .jpeg .png .bmp .gif .tif .tiff`

### 一覧でできること

| 操作 | 方法 |
|---|---|
| 並べ替え | 行をドラッグ、Alt+↑↓、「名前順」 |
| リストから外す | Delete（ファイルは消えない） |
| しおり名を変える | しおり名をダブルクリック、または F2 |
| 使うページを選ぶ | プレビューのページを押す（もう一度押すと戻る）。ページ指定をダブルクリックか F3 で「1-3,5」「8-」のように書いてもよい |
| ページを大きく見る | プレビューのページに乗せて右上の拡大ボタン、または右クリック。← → でページ送り、Space で結合の切り替え、R で回転、Esc で閉じる |
| ページを回す | プレビューのページに乗せて右上の回転ボタン（右に 90°）、または右クリックで左右を選ぶ。結合した PDF に反映される |
| Excel のシートを選ぶ、幅を 1 ページに収める | Excel の行を選び、プレビューの上の「シートと幅の設定...」 |
| パスワード付きファイルを開く | その行をダブルクリック、またはプレビューの上の「パスワードを入力...」 |
| 1 ファイルから選んだページだけを保存する | プレビューの上の「ページを選んで保存...」、または右クリックの「ページを選んで保存...」。全ページが並ぶので、押して選ぶ（Shift を押しながら押すと、前に押したページからそこまでをまとめて選ぶ）。「1-3,10-12」と書いてもよい。選んだページだけで 1 つの PDF を保存し、結合の一覧の設定は変えない |
| 1 ファイルを分割する | プレビューの上の「分割...」、または右クリックの「分割...」。N ページごと・しおりごと・範囲指定（`1-3; 4-8; 9-`）から選び、書き出すファイルを確かめてから分割する（一覧で選んだファイルに入るページが右に並ぶので、切れ目の位置も見られる）。範囲指定では右に書き出すページがすべて並び、ページに乗せて出る「ここから分ける」を押すと、そのページから新しいファイルになる（範囲の欄が書き換わる。「区切りを外す」で戻せる）。結合から外したページは含めず、回したページは回した向きで書き出す |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Y |
| 元のファイルを開く | ファイル名をダブルクリック |

元のファイルを Office で直して保存すると、このウィンドウに戻ったときに自動で変換し直す。

### 仕上がりのオプション

| オプション | 内容 |
|---|---|
| ページ番号を入れる | 各ページの下に「3 / 25」の形で通し番号を入れる |
| 目次ページを付ける | 先頭に、しおり名と開始ページの一覧を付ける。行を押すとそのページへ飛べる |
| 両面印刷用に白紙を挟む | 各ファイルが紙の表（奇数ページ）から始まるように白紙を入れる |
| 作成後に開く | できた PDF をすぐ開く（個別に保存したときは、保存先のフォルダを開く） |

## 出力の決まり

| 種類 | 出力されるもの | しおり |
|---|---|---|
| Word | 変更履歴とコメントは出さず、変更を反映した最終版 | 見出し |
| Excel | 表示されているシート。印刷範囲があるシートはその範囲だけ。ページ設定はブックの設定に従う | シート名（2 枚以上のとき） |
| PowerPoint | 非表示でないスライド | スライドのタイトル |
| PDF | そのまま | 元の PDF のしおり |
| 画像 | A4 の 1 ページに 1 枚（横長なら横向き）。大きければ縮め、小さければ実寸のまま中央に置く。複数ページの TIFF は全ページ | なし |

結合した PDF には、ファイルごとのしおりが付き、その下に上の表のしおりがぶら下がる。結合から外したページを指すしおりは付かない。

## コマンドラインから使う（docs2pdf.exe）

バッチファイル、PowerShell、タスクスケジューラー、エクスプローラーの「送る」メニューからは `docs2pdf.exe` を使う。
画面を出さず、終わるまで待ち、結果を終了コードで返す。
進み具合とエラーは標準エラーに、できたファイルのパスは標準出力に出す。`docs2pdf --help`、`docs2pdf merge --help` で使い方が出る。

### ファイルごとに PDF にする

```
docs2pdf 見積書.docx 請求書.xlsx          見積書.pdf と 請求書.pdf を、それぞれ同じフォルダに作る
docs2pdf 資料フォルダ -o PDF             フォルダの中をサブフォルダも含めて PDF にし、PDF フォルダに書く
```

サブコマンドを付けないと、ファイルごとに「元のファイル名.pdf」を作る。`-o` を省くと、それぞれのファイルと同じフォルダに書く。
入力の PDF はすでに PDF なので飛ばす（フォルダを渡して 2 回実行しても、1 回目にできた PDF をまた PDF にしない）。
名前が重なるときは `報告 (docx).pdf` のように拡張子を添える。`--page-numbers` でページ番号を入れられる。
PDF にできないファイルがあっても、ほかのファイルは書き出し、最後に失敗（終了コード 1）にする。

エクスプローラーの「送る」メニューに登録すると、選んだファイルを右クリックからすぐ PDF にできる。
`Win+R` で `shell:sendto` を開き、`docs2pdf.exe` のショートカットを置く（名前は「PDF にする」など、メニューに出したい言葉にする）。
このように開いた画面では、「2/5 件完了　変換中: 請求書.xlsx」のように 1 行で進み具合を書き換えて見せ、
終わったら 3 秒後（エラーがあったときは 10 秒後）に自動で閉じる。キーを押すとすぐ閉じる。
cmd や PowerShell から実行したときは、その画面を閉じない。出力をファイルなどへ流しているときは、書き換えずに 1 行ずつ出す。

### 結合

```
docs2pdf merge 表紙.docx 資料フォルダ 付録.pdf -o まとめ.pdf --toc --page-numbers
```

| 指定 | 内容 |
|---|---|
| `<入力>...` | ファイルやフォルダ。**書いた順に結合する**（フォルダの中はファイル名の順、数字は数値として比べる） |
| `-o, --out <出力.pdf>` | 作る PDF（必須） |
| `--toc` `--page-numbers` `--duplex` | 目次・ページ番号・両面印刷用の白紙 |
| `--title <題名>` | PDF の文書のタイトル（既定は出力のファイル名） |
| `--open` | 作ったあと開く |

結合できないファイル（パスワード付きなど）が 1 つでもあれば、PDF は作らずに失敗にする。

### 分割

```
docs2pdf split 報告書.pdf --every 10           10 ページごと
docs2pdf split 報告書.pdf --pages 1-3 --pages 4-   範囲ごと（指定した数だけファイルを作る）
docs2pdf split 報告書.docx --bookmarks -o 章ごと     先頭の階層のしおり（Word なら見出し）ごと
```

`報告書_01.pdf`、`報告書_02_第1章 はじめに.pdf` のような名前で書き出す。`-o` を省くと入力と同じフォルダに書く。
Word・Excel・PowerPoint・画像も、PDF にしてから分ける。各ファイルには、その範囲に入る元のしおりが残る。

### 共通

| 指定 | 内容 |
|---|---|
| `-f, --force` | 同じ名前のファイルがあれば上書きする（付けなければ上書きせずに失敗する） |
| `--timeout <分>` | 1 ファイルの変換を待つ時間（既定 5 分） |
| `-q, --quiet` | 進み具合を出さない |

| 終了コード | 意味 |
|---|---|
| 0 | 成功 |
| 1 | 変換・結合・分割に失敗した（ファイルごとに PDF にするときは 1 件でも失敗した）、または上書きを断った |
| 2 | 指定が正しくない（ファイルが見つからない、オプションの組み合わせが違うなど） |
| 130 | Ctrl+C で中止した |

画面版の `DocsToPdf.exe` も `--out` を付けると画面を操作せずに結合できるが、
画面のあるアプリなので cmd や PowerShell は終わりを待たない。スクリプトからは `docs2pdf.exe` を使う。

## 安定して動かすための作り

- Word / Excel / PowerPoint は専用のスレッドで 1 件ずつ処理し、起動したものを続くファイルで使い回す。変換が途切れたら 2 秒で終了させる
- 元のファイルは作業フォルダ（`%TEMP%\DocsToPdf`）にコピーし、その写しを読み取り専用で開く。元のファイルには触らない
- マクロ付きの形式（`.docm` `.xlsm` `.xlsb` `.pptm` など）は、写しからマクロの部品を取り除いてから開く。そのうえで Office はマクロを強制的に無効にして開く（取り除けない古い形式や暗号化されたファイルも、これで動かない）。利用者が開いている Office で変換するときも、変換の間だけ同じ設定にして終わったら戻し、設定できなければ変換しない
- 確認のダイアログを出さない設定にし、Excel のイベントとリンクの更新を止める。Word は開く間だけ「開くときにリンクを更新する」を切り、すぐ元に戻す（利用者の Word の設定なので）
- 「保存時に個人情報を削除する」が設定された文書は、保存のときに警告を出して答えを待つことがあるので、開いた写しの設定だけを切る（元のファイルは変わらない）
- パスワード付きのファイルは入力待ちにせず、パスワードの入力を求める行として表示する
- インターネットから来たファイルの印は写しにも残す（消すと安全側の判断を弱める。印が付いたままでも、確かめた環境では Word・Excel・PowerPoint とも変換できた）
- このツールが起動した Office が確認の画面を出したまま止まったら（画面が出ていて、Office が何もしていない状態が 5 秒続いたら）、その文面を添えて失敗にし、Office を止める
- 1 ファイル 5 分で応答がなければ Office を強制終了し、次のファイルでは起動し直す
- 終了や強制終了をするのは、このツールが起動した Office だけ。利用者が開いている Office は、終了も強制終了もしない
- このツールが起動した見えない Office の中で利用者が別のファイルを開いた場合は、その Office を画面に出して引き渡し、以後は触らない
- ツールが異常終了して Office が残ったときは、次回の起動時に、画面を持たない残り物だけを片付ける
- 保存は一時ファイルに書いてから置き換えるので、途中で失敗しても既存の PDF は壊れない

## ビルドとテスト

.NET 10 SDK と Microsoft Office が必要（Word / Excel / PowerPoint のうち、変換したい形式のもの）。Windows 10 バージョン 2004 以降で動く。
コマンドは、このフォルダ（`docs-to-pdf`）で実行する。

```
dotnet test
dotnet publish src/DocsToPdf -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
dotnet publish src/DocsToPdf.Cli -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

`publish\DocsToPdf.exe`（画面版）と `publish\docs2pdf.exe`（コマンドライン版）が、それぞれ 1 ファイルでできる。
実行には .NET 10 デスクトップ ランタイムが必要。
Release ビルドにはデバッグ情報を付けず、ビルドした PC のフォルダのパスも埋め込まない。

テストは Office を使わない部分（ページ指定、結合、分割、ファイルごとの保存とその名前の決め方、しおり、目次、ページ番号、ページの回転、画像の変換、ファイルの集め方と種類の判定、マクロの取り除き、確認の画面で止まったかの判定）を確かめる。
Office での変換は、実際の Office がないと確かめられないため含めていない。

## 構成

| 場所 | 内容 |
|---|---|
| `src/DocsToPdf.Core` | 変換・結合・分割の本体（画面版とコマンドライン版で共有） |
| `src/DocsToPdf.Core/ConversionService.cs` | 裏で変換する仕組み。Office 用のスレッドと、PDF・画像用の並行処理 |
| `src/DocsToPdf.Core/OfficeApp.cs` | Word / Excel / PowerPoint の起動・変換・終了と、利用者への引き渡し |
| `src/DocsToPdf.Core/PdfMerger.cs` | 結合、しおり、目次、ページ番号、白紙 |
| `src/DocsToPdf.Core/PdfSplitter.cs` | 分割（N ページごと、範囲ごと、しおりごと） |
| `src/DocsToPdf.Core/IndividualPdf.cs` | 結合せずにファイルごとに PDF を書き出す。名前の決め方 |
| `src/DocsToPdf.Core/PdfInfo.cs` | PDF のページの大きさとしおりの読み取り |
| `src/DocsToPdf.Core/ImagePdf.cs` | 画像から PDF を作る |
| `src/DocsToPdf.Core/PageRange.cs` | 「1-3,5」のようなページ指定 |
| `src/DocsToPdf.Core/InputFiles.cs` | 渡されたファイルとフォルダから、扱えるファイルを集める |
| `src/DocsToPdf.Cli` | コマンドライン版（`docs2pdf.exe`） |
| `src/DocsToPdf/Ui/MainForm*.cs` | 画面。一覧の操作は `MainForm.List.cs`、作成は `MainForm.Create.cs` |
| `src/DocsToPdf/Ui/PreviewPane.cs` | プレビュー（Windows の PDF 描画機能を使う） |
| `src/DocsToPdf/Ui/PageViewer.cs` | 1 ページを大きく見るウィンドウ |
| `src/DocsToPdf/Ui/SplitDialog.cs` | 分割の画面 |
| `src/DocsToPdf/Ui/Theme.cs` | ライト / ダークの色 |
| `tests/DocsToPdf.Tests` | 単体テスト（xUnit） |
| `Directory.Build.props` | すべてのプロジェクトで共通のビルド設定 |

設定は `%LOCALAPPDATA%\DocsToPdf\settings.json` に保存される（前回の保存先、オプション、ウィンドウの位置）。

画面の色は Windows の「アプリ モード」（ライト / ダーク）に合わせる。常にどちらかにしたいときは、設定ファイルの `ColorMode` を `"Light"` か `"Dark"` にする（既定は `"System"`）。PDF のページは、どちらのモードでも紙と同じ白で表示する。

## 依存パッケージ

- PDFsharp 6.2.4（MIT）。6.5.0 から AGPL になり、実行時にライセンス検証が入ったため 6.2.x に固定している
- System.Security.Cryptography.Pkcs。PDFsharp 6.2.4 が引き込む版に既知の脆弱性があるため、修正済みの版を直接参照して上書きしている
- System.CommandLine 2.0.6（MIT）。コマンドライン版の引数の解析、ヘルプ、Ctrl+C での中止
- テストのみ: xUnit v3、Microsoft.NET.Test.Sdk
