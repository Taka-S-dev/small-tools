# small-tools

小さなツールを集めたリポジトリ。ツールごとにフォルダを分け、それぞれのフォルダの中で、説明・ビルド・テストが完結する。

| ツール | 内容 | 動く環境 |
|---|---|---|
| [docs-to-pdf](docs-to-pdf/) | Word・Excel・PowerPoint・PDF・画像を、しおり付きの 1 つの PDF にまとめる。ファイルごとの PDF 化と、PDF の分割・ページの抜き出しもできる。画面版とコマンドライン版がある | Windows 10 2004 以降、.NET 10、Microsoft Office |

## 決まり

- ツールは 1 つのフォルダに収め、ほかのツールのフォルダには依存しない
- 配布するときの目印（タグ）は、`docs-to-pdf-v2.0.0` のようにツール名を付ける。タグを push すると、そのツールの exe が Releases に置かれる
- ビルドとテストは、ツールのフォルダを変えて push するたびに GitHub で自動で流れる（`.github/workflows/`）
- 新しいツールを足すときは、ルートの `.gitignore` の許可リストにフォルダを 1 行足し、上の表に行を足す
